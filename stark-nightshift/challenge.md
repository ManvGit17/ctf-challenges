| Category | Flag format |

## Description

> Above Manhattan, a vault door answers to badge. The night shift left it talking to itself.

## What you get

- A web console on `http://localhost:8080` once you run the demo (see [README.md](README.md)).
  Open it in a browser. That's all there is.

## Hints

The hints are ROT13 encoded so you don't read one by accident. Decode only what you need, in
order. Any ROT13 decoder works, for example [rot13.com](https://rot13.com) or CyberChef.

1. `Rirel ybpx fgvyy bcraf sbe fbzrbar. Jung znggref vf jura vg sbetrgf.`
2. `Bar urnegorng gryyf lbh vg vf nyvir. Frireny gryy lbh jura gb rkcrpg gur arkg.`
3. `Ol gur gvzr lbh urne gur yngpu, vg vf nyernql fuhg.`
4. `Gjb pybpxf gryy gur fgbel. Arvgure bar vf jebat, gurl ner tbbq ng qvssrerag guvatf.`
5. `Xabpx ybhqyl naq gur ohvyqvat erzrzoref lbh. Xabpx bapr, naq cerpvfryl.`
